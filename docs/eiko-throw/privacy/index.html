プライバシーポリシー

「えいこを投げ飛ばしました」（以下「本アプリ」）は、開発者（Tadashi Terai）が提供するiPhone向けゲームです。本ポリシーは、本アプリで扱う情報について説明します。

1. 開発者が収集する情報

開発者は、利用者の氏名・メールアドレス・位置情報などの個人情報を収集しません。アカウント登録やログインもありません。

2. 端末内に保存される情報

自己ベストやスタンプ帳などのゲームデータは、利用者のiPhone内にだけ保存されます。開発者のサーバーには送信されません。アプリを削除すると、これらのデータも削除されます。

3. 広告について

本アプリは無料で提供し、広告を表示します。広告の配信には、Google LLCの広告サービス「Google AdMob」を利用しています。AdMobは、広告の表示や成果の測定のために、広告識別子（IDFA）などの情報を扱うことがあります。

  • 広告の追跡（トラッキング）は、初回起動時に表示される確認画面で「許可」した場合にのみ行われます。
  • いつでも「設定」→「プライバシーとセキュリティ」→「トラッキング」から許可を変更できます。
  • AdMobによるデータの扱いについては、Googleのポリシーをご確認ください。

4. アプリ内課金

本アプリは現在、アプリ内課金を提供していません。

5. 子どもの利用について

本アプリは、13歳未満の子どもから個人情報を意図的に収集することはありません。

6. 本ポリシーの変更

内容を変更する場合は、本ページを更新し、必要に応じてアプリ内またはストアで告知します。
